# 한자몬 (설치형 웹앱 배포본)

한국어로 배우는 일본어 글자 몬스터 도감. 히라가나·가타카나·한자 363자를 몬스터 배틀로 잡으며 하루 5분씩 익혀요.

- 앱 주소: https://bamtolking.github.io/kanji-mon-app/
- 아이폰: Safari로 열고 → 공유 버튼 → **홈 화면에 추가**
- 안드로이드: Chrome으로 열고 → 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**

이 저장소에는 빌드된 앱 파일만 있어요. 기록은 각자 기기의 브라우저에만 저장되고, 서버로 보내지 않아요.
